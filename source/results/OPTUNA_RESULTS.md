# Optuna nested CV — сводка результатов

**Дата:** автогенерация ноутбука 11_optuna_tuning.ipynb
**Стратегия:** внешний LOSO/LOO + внутренний GroupKFold (3 для XGB/RF, 2 для LSTM) для Optuna.
**Sampler:** TPESampler(seed=42, n_startup_trials=5).
**Trials per fold:** XGB block 20, RF window 20, LSTM window 15.
**Целевая метрика Optuna:** F1-macro.

## Замечания для диплома

- Все Optuna-исследования выполнялись только на train-субъектах внешнего LOSO/LOO фолда.
- Тестовый субъект внешнего фолда не использовался ни на одном этапе подбора гиперпараметров.
- Финальные метрики получены на полностью held-out субъекте после переобучения с best_params на всём train-наборе фолда.
- Гиперпараметры варьируются между фолдами (как и должны при nested CV) — для production-системы рекомендуется выбрать median/mode значения.
